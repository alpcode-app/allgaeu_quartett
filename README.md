# Allgäu Quartett – Web-Ansicht

Digitale Ansicht der 32 Quartettkarten: drehbares 3D-Gelände, Kartenwerte, aktuelles Wetter (Open-Meteo), Lifte und Pisten.

- Übersicht: `index.html`
- Detail: `karte.html?id=A1`
- Kurze Adressen für die QR-Codes auf den Karten: `k/A1/` … `k/H4/`

Daten und Modelle werden im App-Projekt mit `werkzeuge/web_daten.py` erzeugt.

Gelände: Copernicus DEM GLO-30 (© DLR e.V., © Airbus Defence and Space GmbH, EU/ESA) · Pisten & Lifte: © OpenStreetMap-Mitwirkende (ODbL) · Wetter: Open-Meteo (CC BY 4.0)
